# Gallery Japan

Sitio web tipo galería sobre lugares representativos de Japón.

## Descripción

Este proyecto presenta una galería visual con enlaces a distintos lugares de Japón. Su diseño está pensado para mostrar sitios turísticos, culturales y naturales de forma simple y ordenada.

## Lugares incluidos

- Kōkyo
- Fushimi-ku, Kyoto
- Uozu, Toyama
- Fushimi Inari-taisha
- Pabellón de Oro
- Hakone Shrine
- Monte Fuji
- Monte Kōya

## Tecnologías utilizadas

- HTML5
- CSS3
- GitHub Pages

## Objetivo

Practicar la creación de una galería web usando imágenes, enlaces y una estructura clara para presentar lugares de Japón.
